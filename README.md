# BananaBurner Code

Manage your Bot-Hosting deployments from your editor.

## What it does

- Start, stop, and restart deployments
- View CPU, memory, disk, network, and uptime
- Edit remote files and folders
- Manage environment variables and secrets
- Manage packages
- Edit startup settings
- Use the deployment console
- Manage domains
- Create, restore, and delete backups
- Sync linked Git repositories

## Connect

You can connect with:

- OAuth
- A Bot-Hosting API key

Use the BananaBurner Code icon in the Activity Bar to connect.

## Editors

The extension should work in:

- Visual Studio Code
  - support for Mac OS touch bar
- Cursor
- Antigravity
- Windsurf
- Other VS Code based editors

## Development

Install dependencies:

```sh
npm install
```

Compile the extension:

```sh
npm run compile
```

Run the linter:

```sh
npm run lint
```

Start the extension with the `Run Extension` launch configuration in VS Code.
